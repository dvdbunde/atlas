# Archived Plans Directory

This directory stores completed or superseded plans for historical reference. Move a plan here after it has been approved, executed, and superseded by newer plans.

## Archive Conventions

Archived plans are retained for historical traceability. Their descriptions of scope, status, architecture, or implementation should not automatically be treated as the current state of the project. When a newer plan supersedes an older one, retain the older document and identify the newer source of truth through links or status notes where practical.
