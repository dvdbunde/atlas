# M12-005 --- Officer pages restyling

## Objective

Apply the M12 visual language to the existing Officer pages while
preserving the current review workflow and information architecture.

## Context

Officer screens need greater information density and scanability than
Citizen screens, but remain part of the same ATLAS visual system.

## Requirements

- Restyle the existing Officer Dashboard.
- Restyle the existing Officer Application Review page.
- Preserve the existing review actions, application information,
    documents, notes, history, and status presentation.
- Use existing shared components after M12-003.
- Improve hierarchy and density through styling and small layout
    adjustments only.
- Validate the Officer Dashboard and Review screens against the
    approved visual direction.

## Relevant files / areas

- `src/ATLAS.Blazor/Components/Pages/OfficerDashboard.razor`
- `src/ATLAS.Blazor/Components/Pages/OfficerApplicationReview.razor`
- `src/ATLAS.Blazor/Components/Shared/`

## Acceptance criteria

- [ ] Officer Dashboard retains all existing content and actions with
    M12 styling.
- [ ] Officer Review retains all existing workflow actions and
    information with M12 styling.
- [ ] Status, applicant/application details, documents, activity, and
    review controls are visually coherent.
- [ ] Tables/lists remain information-dense without unnecessary
    decoration.
- [ ] No new Officer functionality is introduced.
- [ ] Existing review workflow remains unchanged.
- [ ] Representative desktop and narrow layouts remain usable.

## Testing

- [ ] Run relevant Officer/review tests.
- [ ] Exercise existing review workflow actions.
- [ ] Verify status and validation presentation.
- [ ] Perform keyboard and responsive checks.

## Documentation

- [ ] None required.

## Constraints

- Preserve the existing Officer workflow.
- Do not rebuild the review page.
- Do not add imagined queue/task/report functionality.
- Prefer CSS-first changes.

## Notes

Primary visual references: supplied Officer Dashboard and Officer Review
screenshots/mockups.
