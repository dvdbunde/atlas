# M12-002 --- Existing application shell and navigation restyling

## Objective

Restyle the existing ATLAS application shell, sidebar, top row, and
role-based navigation without changing their functional structure.

## Context

The current shell uses the standard Blazor layout and a blue/purple
gradient sidebar. M12 replaces that appearance with a professional,
restrained application shell.

## Requirements

- Restyle `MainLayout` using the M12 visual foundation.
- Replace the current sidebar gradient with the solid dark-navy shell
    treatment.
- Retain all existing role-based navigation entries and destinations.
- Restyle active, hover, focus, and normal navigation states.
- Restyle the existing top row/header as a clean light application
    header.
- Improve shell spacing and content proportions where needed.
- Preserve existing sign-in/sign-out and user identity behaviour.
- Preserve responsive navigation behaviour.

## Relevant files / areas

- `src/ATLAS.Blazor/Components/Layout/MainLayout.razor`
- `src/ATLAS.Blazor/Components/Layout/MainLayout.razor.css`
- `src/ATLAS.Blazor/Components/Layout/NavMenu.razor`
- `src/ATLAS.Blazor/Components/Layout/NavMenu.razor.css`
- `src/ATLAS.Blazor/Components/Layout/ReconnectModal.razor`
- `src/ATLAS.Blazor/Components/Layout/ReconnectModal.razor.css`

## Acceptance criteria

- [ ] Sidebar uses the approved solid navy treatment with no
    blue/purple gradient.
- [ ] Existing navigation items and role-based visibility are
    unchanged.
- [ ] Active, hover, and focus states are visually clear and
    accessible.
- [ ] Top bar is visually integrated with the new shell.
- [ ] Main content has a consistent container and page spacing
    treatment.
- [ ] Existing authentication/account interactions remain functional.
- [ ] Shell remains usable at narrow viewport widths.

## Testing

- [ ] Run existing relevant tests.
- [ ] Verify Citizen, Officer, and Admin navigation destinations.
- [ ] Keyboard-test navigation and account controls.
- [ ] Check desktop and narrow/mobile viewport behaviour.

## Documentation

- [ ] None required unless implementation materially changes the
    approved shell specification.

## Constraints

- Preserve existing shell structure and role-based navigation.
- No new navigation items.
- No page/component rebuild.
- No business or authentication changes.

## Notes

Build on M12-001 rather than introducing shell-specific colours or
typography.
